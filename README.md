# Odin Recipes

A simple recipe website built as part of **The Odin Project** Foundations course.

## About

This project is designed to practice the fundamentals of HTML by creating a basic recipe website. It will include a main index page with links to individual recipe pages.

## Skills Demonstrated

By completing this project, I will practice:

- Writing semantic HTML
- Creating links between pages
- Working with lists
- Adding images
- Organizing files and folders
- Using Git and GitHub for version control
